# Path-Finder

**운전대를 놓을 수 없는 사람들: 데이터로 찾은 고령자 면허 반납 사각지대**

> 2026 한겨레 × 재단법인 숲과나눔 「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」 출품작

## 한 줄 요약

고령자 면허 반납 정책은 대중교통이 있는 곳에서만 작동합니다. 수도권(서울·경기·인천)을 대상으로 고령 운전 위험, 대중교통 접근성, 고령자 이동 실태를 겹쳐 "반납하면 갈 곳이 없는" 반납 사각지대를 찾습니다.

## 분석 질문

1. 대중교통 접근성이 낮은 지역일수록 고령자 면허 반납률이 낮은가?
2. 반납률은 지원금 액수보다 대체 이동수단 유무로 더 잘 설명되는가?
3. 대중교통 취약 지역의 고령자는 병원 이동이 억눌려 있는가?

## 폴더 구조

```
Path-Finder/
├── data/
│   ├── raw/          # 원자료 (Git에 올리지 않음, data/README.md 참고)
│   └── processed/    # 가공 데이터 (용량이 작은 결과만)
├── notebooks/        # 분석 노트북 (번호 순서대로 실행)
├── outputs/
│   ├── figures/      # 기획서용 그림
│   ├── tables/       # 결과 표
│   └── llm/          # LLM 프롬프트와 원본 출력 (재현성용)
├── requirements.txt
└── .env.example
```

### 노트북 (작성 중)

| 번호 | 파일 | 내용 |
| --- | --- | --- |
| 01 | `01_accident_risk.ipynb` | 시군구별 고령 운전자 사고 위험도 |
| 02 | `02_transit_access.ipynb` | 행정동별 대중교통 접근성 지수 |
| 03 | `03_senior_mobility.ipynb` | 70세 이상 병원 목적 이동량 |
| 04 | `04_ordinance_llm.ipynb` | 면허 반납 지원 조례 LLM 구조화 |
| 05 | `05_overlay.ipynb` | 지표 중첩, 반납 사각지대 도출 |

## 실행 방법

```bash
pip install -r requirements.txt
cp .env.example .env   # API 키 입력
```

1. `data/README.md`를 따라 원자료를 `data/raw/`에 내려받습니다.
2. `notebooks/`의 노트북을 번호 순서대로 실행합니다.
3. 결과는 `outputs/`에 저장됩니다.

## AI 활용

- **조례 구조화 (04):** 지자체별 면허 반납 지원 조례와 공고문을 LLM에 입력해 지원 연령, 금액, 지급 형태, 1회성 여부, 대중교통 연계 여부를 추출합니다.
- **검증:** 추출 결과 중 30건을 사람이 원문과 대조해 정확도를 보고합니다. (결과 기재 예정)
- **재현성:** 사용한 프롬프트와 LLM 원본 출력은 `outputs/llm/`에 저장합니다.

## 데이터 한계

- 생활이동 데이터는 통신 데이터 기반 추정치이며, '차량' 수단은 직접 운전과 동승·택시를 구분하지 않습니다.
- 시군구 단위 고령 면허 소지자 데이터가 확보되기 전까지 사고 위험도는 고령 인구 기준으로 정규화합니다.
