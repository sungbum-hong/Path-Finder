# Path-Finder

**수도권 지역별 고령 운전자 교통사고 위험 및 버스 접근성 분석을 통한 맞춤형 예방대책 제안**

> 2026 「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」 (한겨레 × 재단법인 숲과나눔) 출품작
> 팀 Path Finder: 홍성범, 김상훈, 정서연

## 한 줄 요약

고령 운전자 사고는 도심에서 잦고 외곽에서 치명적이며, 외곽 고령자는 버스가 멀고 드물어 차로 멀리 이동합니다. 수도권 66개 시군구에서 사고 위험과 교통 취약성이 겹치는 우선 검토 지역(경기 10곳)을 찾고, 지역 유형별 대책을 제안했습니다.

## 분석 흐름

| 단계 | 내용 | 노트북 |
| --- | --- | --- |
| 1 | 고령 운전자 교통사고 위험 (고령인구 1만 명당 사고율, 치사율, 2023→2025 변화) | `notebooks/01_accident_risk` |
| 2 | 버스 접근성 (정류장 300m 안 고령인구 비율, 배차 중앙값, 종합 등급) | `notebooks/02_bus_access` |
| 3 | 고령자의 실제 이동 (수도권 생활이동: 1명당 이동, 차량 비중, 이동거리) | `notebooks/03_senior_mobility` |
| 4 | 사고 위험 × 교통 취약성 중첩 (A~D 유형, 세부 유형, 강건성) | `notebooks/04_overlay` |
| 5 | 면허 반납과 대체 교통수단 (지방청 반납, 서울 면허 보유율, DRT 공백) | `notebooks/05_license_return` |
| 6 | 보고서 그림 (그림 1·4·5) | `notebooks/06_report_figures` |

분석 단위는 서울 25개 구, 인천 10개 구·군, 경기 31개 시·군(일반구는 시로 합산) 등 66개 시군구이며, 주요 기간은 2023~2025년입니다.

## 폴더 구조

```
Path-Finder/
├── data/
│   ├── raw/          # 원자료 (용량 때문에 Git에 올리지 않음, 아래 '활용 데이터'에서 내려받기)
│   └── processed/    # 가공 데이터
├── notebooks/        # 단계별 분석 코드 (번호 순서대로 실행)
├── outputs/
│   ├── figures/      # 보고서 그림 (report_fig1~5)
│   └── tables/       # 결과표 (자료조사4_최종결과.xlsx, 자료조사5_대체교통_현황.xlsx 등)
└── requirements.txt
```

## 실행 방법

```bash
pip install -r requirements.txt
```

1. 아래 '활용 데이터'의 원자료를 `data/raw/`에 내려받습니다.
2. `notebooks/`의 코드를 01부터 순서대로 실행합니다. (Google Colab에서도 실행 가능)
3. API 수집 코드는 공공데이터포털 인증키가 필요합니다. 키는 `.env.example`을 `.env`로 복사해 넣고, 저장소에는 올리지 않습니다.
4. 보고서 그림은 `python notebooks/06_report_figures/make_report_figures.py`로 다시 만들 수 있습니다. (한글 폰트: 나눔고딕)

## 주요 결과

- 수도권 고령 운전자 가해사고는 2023년 17,255건에서 2025년 20,496건으로 18.8% 늘어 고령인구 증가율(12.8%)을 웃돌았습니다.
- 정류장이 먼 곳일수록 버스도 드물었고(ρ = -0.82), 정류장 300m 밖 고령자는 126.0만 명(2025)입니다.
- 1명당 하루 이동은 접근성과 관계없었지만(p = 0.27), 70세 이상 차량 이동 비중은 접근성 상 18% → 하 57%였습니다(ρ = -0.92).
- 사고율과 접근성은 무관했지만 치사율은 접근성이 낮을수록 높았습니다(ρ = -0.54). 우선 검토(A형)는 경기 10곳입니다.
- 접근성 '하' 20곳 중 7곳은 수요응답형 교통 근거가 없습니다(정류장 300m 밖 고령자 약 19.0만 명).
